## Como acompanhar

O [link principal do projeto](../README.md) continua sendo o endereço para compartilhar com os amigos. Ele sempre apontará para o patch atual quando uma nova atualização for publicada. As notas de cada patch ficam preservadas neste diretório; a versão inicial também permanece no [histórico técnico](../CHANGELOG.md).

Para uma próxima atualização, registre as mudanças seguindo [o modelo de notas](MODELO.md). O índice, o guia de macros e o pacote para download devem acompanhar o estado publicado, sem declarar testes de combate que ainda não foram realizados.
